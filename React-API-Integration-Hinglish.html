TOPIC 02

fetch() API — Native Browser

fetch() browser ka built-in function hai — koi library install nahi karna. Promise return karta hai. Lekin kuch limitations bhi hain jo Axios solve karta hai.

2.1 Basic GET Request

// ---- Method 1: Promise chain ---- fetch('https://jsonplaceholder.typicode.com/posts') .then(response => { // fetch kisi bhi status pe resolve hota hai (200 ya 404 dono!) // Isliye manually check karo: if (!response.ok) { throw new Error(`HTTP Error: ${response.status}`); } return response.json(); // Response body ko JSON mein parse karo }) .then(data => console.log(data)) .catch(err => console.error('Error:', err)); // ---- Method 2: async/await (cleaner!) ---- async function getPosts() { try { const response = await fetch('https://jsonplaceholder.typicode.com/posts'); if (!response.ok) { throw new Error(`Server Error: ${response.status}`); } const posts = await response.json(); console.log(posts); // Array of posts return posts; } catch (error) { console.error('Fetch failed:', error.message); throw error; // Caller ko error propagate karo } }

Important: fetch() 404 ya 500 pe bhi resolve hota hai — reject nahi hota! Network failure pe hi reject hota hai. Isliye response.ok ya response.status hamesha check karo.

2.2 POST Request — Data Bhejna

async function createPost(postData) { const response = await fetch('https://jsonplaceholder.typicode.com/posts', { method: 'POST', // HTTP method headers: { 'Content-Type': 'application/json', // Bata rahe ho body JSON hai 'Authorization': `Bearer ${localStorage.getItem('token')}` }, body: JSON.stringify(postData) // Object ko string mein convert karo }); if (!response.ok) { const errorData = await response.json(); // Error details server se throw new Error(errorData.message || 'Create fail hua'); } return response.json(); // Naya created resource } // Use karna: createPost({ title: 'My Post', body: 'Content here', userId: 1 }) .then(newPost => console.log('Created:', newPost));

2.3 fetch() Limitations

  • Har request mein headers manually likhne padte hain
  • Response.ok manually check karna padta hai
  • Request/Response interceptors nahi hain
  • Upload progress track nahi hoti
  • Automatic JSON parse nahi hota
  • Request timeout built-in nahi hai

Kab use karein: Simple projects mein fetch() theek hai. Production apps mein Axios prefer karo — less boilerplate, more features.

Axios — Production-Ready HTTP Client

Axios fetch() ke saare problems solve karta hai — auto JSON, interceptors, instances, error handling, timeout, upload progress — sab built-in.

3.1 Axios Instance — Best Practice Setup

// src/api/axiosInstance.js — Ek baar setup, har jagah use import axios from 'axios'; const api = axios.create({ baseURL: import.meta.env.VITE_API_URL || 'http://localhost:8000/api', timeout: 10000, // 10 seconds — iske baad request fail headers: { 'Content-Type': 'application/json', 'Accept': 'application/json' } }); // ---- REQUEST INTERCEPTOR ---- // Har request se pehle run hota hai api.interceptors.request.use( (config) => { const token = localStorage.getItem('token'); if (token) { config.headers.Authorization = `Bearer ${token}`; // Auto token! } return config; }, (error) => Promise.reject(error) ); // ---- RESPONSE INTERCEPTOR ---- // Har response ke baad run hota hai api.interceptors.response.use( (response) => response, // Success — as is return karo (error) => { if (error.response?.status === 401) { // Token expire ho gaya — logout karo localStorage.removeItem('token'); window.location.href = '/login'; } if (error.response?.status === 403) { console.error('Access denied!'); } return Promise.reject(error); // Error propagate karo } ); export default api;

useEffect + API Calls

React mein API call karne ka standard pattern — useEffect mein fetch, useState mein loading/error/data states. Cleanup bhi zaroori hai memory leak rokne ke liye.

4.1 useEffect API Pattern — Complete

import React, { useState, useEffect } from 'react'; import api from '../api/axiosInstance'; function UsersList() { // 3 states — har API call ke liye ye zaroori hain const [users, setUsers] = useState([]); // Data const [loading, setLoading] = useState(true); // Loading state const [error, setError] = useState(null); // Error message useEffect(() => { // ⚠️ useEffect mein direct async nahi likh sakte // Isliye inner async function banao let isMounted = true; // Cleanup ke liye flag async function fetchUsers() { try { setLoading(true); setError(null); // Previous error clear karo const { data } = await api.get('/users'); // Component abhi mounted hai toh hi setState karo if (isMounted) { setUsers(data); } } catch (err) { if (isMounted) { setError(err.response?.data?.message || 'Users load nahi hue'); } } finally { if (isMounted) setLoading(false); } } fetchUsers(); // Cleanup function — component unmount pe run hogi return () => { isMounted = false; }; }, []); // [] = sirf mount pe run karo // ---- Conditional Rendering ---- if (loading) return <div className="spinner">Loading...</div>; if (error) return <div className="error">{error}</div>; if (!users.length) return <p>Koi user nahi mila</p>; return ( <ul> {users.map(user => ( <li key={user.id}>{user.name} — {user.email}</li> ))} </ul> ); }

Memory Leak: Component unmount hone ke baad setState call karne se React warning deta hai. isMounted flag ya AbortController se isko prevent karo.

Har component mein loading/error/data repeat likhna bad practice hai. Custom hooks mein yeh logic ek baar likho, har jagah reuse karo.

5.1 useFetch — Generic Data Fetching Hook

// src/hooks/useFetch.js import { useState, useEffect, useCallback } from 'react'; import api from '../api/axiosInstance'; export function useFetch(url, options = {}) { const [data, setData] = useState(null); const [loading, setLoading] = useState(true); const [error, setError] = useState(null); // useCallback — function reference stable rakho const fetchData = useCallback(async () => { if (!url) return; try { setLoading(true); setError(null); const { data: responseData } = await api.get(url, options); setData(responseData); } catch (err) { setError(err.response?.data?.message || err.message); } finally { setLoading(false); } }, [url]); // url change hone pe refetch useEffect(() => { fetchData(); }, [fetchData]); // refetch manually call karo return { data, loading, error, refetch: fetchData }; } // ---- Component mein use karna — kitna clean! ---- function PostsList() { const { data: posts, loading, error, refetch } = useFetch('/posts'); if (loading) return <Spinner />; if (error) return <p>Error: {error} <button onClick={refetch}>Retry</button></p>; return <ul>{posts?.map(p => <li key={p.id}>{p.title}</li>)}</ul>; }

5.2 useMutation — POST/PUT/DELETE Hook

// src/hooks/useMutation.js import { useState } from 'react'; import api from '../api/axiosInstance'; export function useMutation(url, method = 'post') { const [loading, setLoading] = useState(false); const [error, setError] = useState(null); const [data, setData] = useState(null); const mutate = async (payload, dynamicUrl) => { try { setLoading(true); setError(null); const endpoint = dynamicUrl || url; const { data: response } = await api[method](endpoint, payload); setData(response); return { success: true, data: response }; } catch (err) { const msg = err.response?.data?.message || err.message; setError(msg); return { success: false, error: msg }; } finally { setLoading(false); } }; return { mutate, loading, error, data }; } // ---- Use karna ---- function CreateForm() { const { mutate, loading, error } = useMutation('/posts', 'post'); const handleSubmit = async (formData) => { const result = await mutate(formData); if (result.success) alert('Created!'); }; }

7.1 Login Flow — Token Store karna

// src/api/authApi.js import api from './axiosInstance'; export const authApi = { login: (credentials) => api.post('/auth/login', credentials), register: (data) => api.post('/auth/register', data), logout: () => api.post('/auth/logout'), refreshToken: () => api.post('/auth/refresh'), getProfile: () => api.get('/auth/me'), }; // src/components/LoginForm.jsx function LoginForm() { const [credentials, setCredentials] = useState({ email: '', password: '' }); const [loading, setLoading] = useState(false); const [error, setError] = useState(null); const handleLogin = async (e) => { e.preventDefault(); setLoading(true); setError(null); try { const { data } = await authApi.login(credentials); // Token store karna — Options: localStorage.setItem('token', data.access_token); // Option 1: localStorage sessionStorage.setItem('token', data.access_token); // Option 2: sessionStorage // Option 3: HttpOnly Cookie (server side — most secure) // Option 4: Redux state (in-memory, clears on refresh) // Refresh token bhi store karo (agar hai) localStorage.setItem('refresh_token', data.refresh_token); window.location.href = '/dashboard'; // Redirect } catch (err) { setError(err.response?.data?.message || 'Login fail hua'); } finally { setLoading(false); } }; return ( <form onSubmit={handleLogin}> {error && <p style={{color:'red'}}>{error}</p>} <input type="email" value={credentials.email} onChange={e => setCredentials(prev => ({...prev, email: e.target.value}))} /> <input type="password" value={credentials.password} onChange={e => setCredentials(prev => ({...prev, password: e.target.value}))} /> <button type="submit" disabled={loading}> {loading ? 'Logging in...' : 'Login'} </button> </form> ); }

7.2 Auto Token Refresh — Interceptor Pattern

// Jab 401 aaye toh refresh karo, phir original request retry karo let isRefreshing = false; let failedQueue = []; const processQueue = (error, token = null) => { failedQueue.forEach(prom => { error ? prom.reject(error) : prom.resolve(token); }); failedQueue = []; }; api.interceptors.response.use( response => response, async (error) => { const originalRequest = error.config; if (error.response?.status === 401 && !originalRequest._retry) { if (isRefreshing) { // Refresh chal raha hai — queue mein add karo return new Promise((resolve, reject) => { failedQueue.push({ resolve, reject }); }).then(token => { originalRequest.headers.Authorization = `Bearer ${token}`; return api(originalRequest); }); } originalRequest._retry = true; isRefreshing = true; try { const { data } = await authApi.refreshToken(); const newToken = data.access_token; localStorage.setItem('token', newToken); api.defaults.headers.Authorization = `Bearer ${newToken}`; processQueue(null, newToken); return api(originalRequest); // Original request retry karo } catch (refreshError) { processQueue(refreshError, null); localStorage.removeItem('token'); window.location.href = '/login'; return Promise.reject(refreshError); } finally { isRefreshing = false; } } return Promise.reject(error); } );

Security Tip: Token localStorage mein store karna XSS attacks ke liye vulnerable hai. Production mein HttpOnly cookies prefer karo — JavaScript se access nahi hoti.

10.2 WebSocket — Custom Hook

// src/hooks/useWebSocket.js import { useState, useEffect, useRef, useCallback } from 'react'; export function useWebSocket(url) { const [messages, setMessages] = useState([]); const [status, setStatus] = useState('disconnected'); // connecting|open|closed const wsRef = useRef(null); // WebSocket object store karo const reconnectRef = useRef(null); const connect = useCallback(() => { setStatus('connecting'); const ws = new WebSocket(url); wsRef.current = ws; ws.onopen = () => { setStatus('open'); console.log('WebSocket connected!'); }; ws.onmessage = (event) => { try { const parsed = JSON.parse(event.data); // JSON parse karo setMessages(prev => [...prev, parsed]); } catch { setMessages(prev => [...prev, event.data]); // Plain text } }; ws.onerror = (error) => { console.error('WebSocket error:', error); setStatus('error'); }; ws.onclose = () => { setStatus('disconnected'); // Auto-reconnect 3 seconds baad reconnectRef.current = setTimeout(connect, 3000); }; }, [url]); useEffect(() => { connect(); return () => { clearTimeout(reconnectRef.current); wsRef.current?.close(); // Cleanup — connection close karo }; }, [connect]); // Message send karne ka function const sendMessage = useCallback((message) => { if (wsRef.current?.readyState === WebSocket.OPEN) { wsRef.current.send(JSON.stringify(message)); } else { console.warn('WebSocket not open yet!'); } }, []); return { messages, status, sendMessage }; } // ---- Chat Component ---- function ChatRoom({ roomId }) { const [input, setInput] = useState(''); const { messages, status, sendMessage } = useWebSocket( `wss://api.example.com/chat/${roomId}` ); const handleSend = () => { if (!input.trim()) return; sendMessage({ type: 'message', text: input, user: 'Kayum' }); setInput(''); }; return ( <div> <p>Status: {status}</p> <div>{messages.map((m, i) => <p key={i}>{m.user}: {m.text}</p>)}</div> <input value={input} onChange={e => setInput(e.target.value)} /> <button onClick={handleSend}>Send</button> </div> ); }

11.2 GraphQL with fetch() — Basic

Interview Questions

React API integration ke most asked interview questions — concept + code dono taraf se.

12.1 Common Questions

Q1: useEffect mein async function directly kyun nahi likh sakte?

useEffect callback ko cleanup function (ya nothing) return karna hota hai. Async function hamesha Promise return karta hai — jo cleanup nahi hai. Isliye inner async function banao aur call karo.

Q2: Memory leak kab hota hai aur kaise rokein?

Component unmount ke baad setState call karne pe. Solution: isMounted flag ya AbortController use karo. Cleanup function return karo useEffect se jo mounted flag false kare.

Q3: fetch() aur Axios mein main difference kya hai?

fetch() 4xx/5xx pe reject nahi karta — manual response.ok check chahiye. Axios automatically throw karta hai. Axios ke paas interceptors, timeout, upload progress, base URL — sab built-in hain.

Q4: Axios interceptors kab aur kyun use karte hain?

Request interceptor: har request mein auto auth token lagao. Response interceptor: 401 pe auto logout ya token refresh karo. DRY principle — ek jagah logic, har request pe apply.

Q5: AbortController kab use karein?

Search input pe — har keystroke pe nayi request, pehli cancel. Component unmount pe pending requests cancel karo. useEffect cleanup mein controller.abort() call karo.

Q6: PUT vs PATCH mein kya fark hai?

PUT = poora resource replace karo (sab fields bhejo). PATCH = sirf specific fields update karo. Partial update ke liye PATCH zyada efficient hai.

Q7: Custom hook kyun banate hain API calls ke liye?

DRY (Don't Repeat Yourself). loading/error/data pattern har component mein repeat hota hai. Custom hook mein ek baar likho, reuse karo. Testing bhi easier hoti hai.

Q8: Promise.all aur Promise.allSettled mein kya fark hai?

Promise.all: koi ek fail → sab fail. Promise.allSettled: sab complete hone tak wait karo, success aur failure dono handle karo. Independent requests ke liye allSettled better hai.

Q9: File upload mein Content-Type header manually set karna chahiye kya?

Nahi! FormData ke liye browser automatically multipart/form-data + boundary set karta hai. Manually set karoge toh boundary missing hogi aur upload fail hoga.

Q10: HTTP vs WebSocket — kab kya use karein?

HTTP: CRUD operations, one-time data fetch. WebSocket: real-time bidirectional — chat, live notifications, collaborative editing, gaming. WebSocket overhead zyada hai toh sirf jab truly real-time chahiye.
