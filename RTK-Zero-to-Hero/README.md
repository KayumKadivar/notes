## 📚 Curriculum Overview

### Part 1: Redux Foundations
- **Module 1** — Redux kya hai, prop drilling, single source of truth
- **Module 2** — Store, Action, Reducer, Dispatch, Pure functions, Immutability
- **Module 3** — Plain Redux ki problems → RTK ka introduction

### Part 2: Redux Toolkit Basics
- **Module 4** — configureStore, DevTools, middleware setup
- **Module 5** — createSlice deep dive, Immer ka role
- **Module 6** — React integration, useSelector, useDispatch, folder structure
- **Module 7** — extraReducers, cross-slice communication

### Part 3: Async Logic
- **Module 8** — createAsyncThunk, pending/fulfilled/rejected, loading states
- **Module 9** — Real-world CRUD app with createAsyncThunk

### Part 4: RTK Query (Core Focus)
- **Module 10** — RTK Query kya hai, kyun better hai
- **Module 11** — createApi, fetchBaseQuery, prepareHeaders, auth tokens
- **Module 12** — Queries, caching, isLoading vs isFetching, polling, skip
- **Module 13** — Mutations, providesTags, invalidatesTags — complete guide
- **Module 14** — useLazyQuery, transformResponse, optimistic updates, prefetching
- **Module 15** — Complete CRUD project — Posts Manager App

### Part 5: Best Practices
- **Module 16** — Feature-based folder structure, barrel files, custom hooks
- **Module 17** — RTK Query vs React Query vs Axios+useEffect comparison

### Part 6: Interview Prep
- **Module 18** — 30 Interview Questions with detailed answers
- **Module 19** — Complete Cheat Sheet — quick reference
